# Tasks — phase index

The folder is the state: `backlog/` → `active/` (keep to 1–2) → `done/`. Status inside a backlog task:
`ready` · `blocked` (by T-nnn) · `gated` (waiting on an OQ answer) · `open` (a Phase 0 question).
Size: S < 1 day, M 1–3 days, L ≥ 1 week. **Release** is the roadmap release of source §15 (R1–R5);
R4 and R5 tasks are deliberately coarse and get split when they become active.

Requirement → task coverage: [`../fsd/traceability.md`](../fsd/traceability.md) (generated by `tools/trace.py --write`).
